## Local Development & Build

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Dev Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000`.

### 3. Production Build
```bash
npm run build
```
Generates production-ready, minified static files in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## Deployment (1-Click Free Hosting)

This static site has zero server vulnerabilities and can be deployed in seconds to any static host:

### Cloudflare Pages / Vercel / Netlify
1. Connect your GitHub repository: `https://github.com/qaansari/eliyaproductionweb`
2. **Framework Preset:** Vite
3. **Build Command:** `npm run build`
4. **Output Directory:** `dist`

### Direct FTP / Apache / Nginx / cPanel
Upload the contents of the `dist/` folder directly to your `public_html` directory.
